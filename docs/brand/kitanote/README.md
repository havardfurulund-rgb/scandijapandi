# 北の手 · Kita no Te: brand reference (from Havard, 01.10.2026)

Source: `KitaNoTe_Designprofil_v1.pdf` (SKM Nordic AS, September 2026). Only the web-relevant parts are committed:

- `BRAND_GUIDE.md`: names, mark, colours, typography, voice (verbatim from the design profile).
- `designprofil-sNN.jpg`: low-res renders of design-profile pages 2 (purpose), 4 (mark), 5 (colours), 6 (typography), 7 (photography), 8 (fixed video elements) and 10 (voice and text).
- `ref-*.jpg`: the opening plate, end card, YouTube thumbnail and subtitle-style templates. These are layout references for the web cover, product block and captions.
- Logo SVGs live in `public/brand/kitanote/`. The `logo_mark_only*.svg` files contain no text and are safe to use as `<img>` or inline. The wordmark and stacked SVGs contain `<text>`, which needs Noto Serif JP, Fraunces and Jost. On the web, render the wordmark as HTML text next to the mark instead.

Not committed (internal or not web assets): the full PDF, the production bible (contract text), the channel/season plan, the localisation pipeline and the full-size PNG exports.
